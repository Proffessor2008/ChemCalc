# ChemCalc

Адаптивный химический калькулятор на HTML, CSS и JavaScript. Локальные расчёты не используют внешние API. Node.js backend с SQLite поддерживает аккаунты, предложения сообщества, голосование и модерацию. Service worker кеширует интерфейс и подтверждённые правила для офлайн-работы.

## Запуск

Нужен Node.js 22.13+ с встроенным `node:sqlite`; рекомендуется Node.js 24. Дополнительные пакеты и сборщик не требуются.

```bash
npm start
```

Откройте `http://127.0.0.1:8080`. Эта команда запускает и сайт, и API сообщества. Для калькулятора без аккаунтов подойдёт `npm run start:static` или любой статический HTTP-сервер; вкладка сообщества в этом случае недоступна. Открытие через `file://` не поддерживается.

### Первый вход GOD

При **пустой** таблице пользователей сервер один раз создаёт единственного GOD и выводит его логин и пароль в терминал. По умолчанию логин — `creator`, пароль локального запуска генерируется случайно. Сохраните его: после создания базы повторный вывод не выполняется.

Для собственного первичного пароля задайте переменные **до первого запуска**:

```bash
COMMUNITY_GOD_LOGIN=creator COMMUNITY_GOD_PASSWORD='ваш-длинный-пароль' npm start
```

Для публичного запуска используйте HTTPS, `NODE_ENV=production`, сильный `COMMUNITY_GOD_PASSWORD`, резервное копирование `var/community.db` и ограничение доступа к каталогу `var`. Не публикуйте пароль или базу в репозитории. Статический GitHub Pages/Netlify не исполняет Node.js backend: для сообщества нужен отдельный хостинг Node.js с постоянным диском.

Тесты и проверка согласованности данных:

```bash
npm test
npm run validate:data
```

`tests.html` строит карточки всех 118 элементов в реальном браузерном DOM, проверяет PWA и выполняет 12 smoke-сценариев вычислений, включая P + HNO₃, CrCl₃ + H₂O₂ + KOH и блокировку обмена в органической среде. `tests/phase-guard.test.js` проверяет 273 сценария по фазам, флагам и аналогичным реакциям.

`tests/reaction-audit-expansion.test.js` охватывает расширенный пакет обменных, кислотно-основных, органических, гидролитических и термических реакций. Неверный эталон NH₄I + 2HNO₃ = N₂O + I₂ + 3H₂O отмечен как неуравновешенный; используется согласованная схема с I₂ и NO₂. Для H₃PO₄ + NaOH при недостатке основания теперь поддерживается NaH₂PO₄ вместо прежнего отказа от прогноза.

## Возможности

- Парсер вложенных формул, кристаллогидратов, ионов и электронов.
- Точное уравнивание на рациональных дробях BigInt, включая заряд.
- Режимы «Проверка» и «Авто», типовые правила оксидов, гидроксидов, органических реакций и взаимного гидролиза.
- Ионные ОВР по полуреакциям с проверкой атомов, заряда, электронов и положительной стандартной ЭДС; диспропорционирование и расчёт ЭДС по Нернсту при заданных активностях.
- Внутримолекулярные ОВР разложения NH₄NO₃, NH₄NO₂, (NH₄)₂Cr₂O₇ и KClO₃: отдельные центры окисления и восстановления и полный перенос электронов для уравненной реакции. Термическое разложение одиночных веществ поддерживается отдельными правилами.
- Вычисление степеней окисления бинарных оксидов по электронейтральности, а не по шаблону газа; учёт неизменных ионных центров перед электронным балансом.
- Правила неметаллов P/P₄, S и C с концентрированными HNO₃ и H₂SO₄, трёхкомпонентные ОВР с кислотой или щёлочью, окисление Cr(III) и Mn(II) пероксидом.
- Полные и краткие ионные уравнения, включая уже ионный ввод и соли аммония; отдельные ступенчатые равновесия слабых кислот с Ka/pKa. В расплаве и газовой фазе ионная форма заменяется пояснением о безводной среде.
- Единый фазовый барьер: водные ионные механизмы не переносятся в органический растворитель, расплав или газ. Правила для конкретной неводной фазы сохраняются, включая электролиз расплава, разложение и соединение металлов с галогенами и серой.
- Амфотерные соли Al(III), Zn(II), Cr(III) и Be(II) образуют гидроксокомплексы при выбранном избытке щёлочи.
- Общее правило взаимодействия растворимых солей аммония с щёлочами при нагревании действует как в нейтральной, так и в щелочной среде.
- Стехиометрия: масса, моли, газы, растворы, лимитирующий реагент и выход выбранного продукта.
- Термодинамика по закону Гесса, K и приближение ΔG(T), с выбором записи по фазе и изомеру; отдельный расчёт по краткому ионному уравнению.
- Документация и новые сообщения интерфейса на русском и английском языках.
- Экспорт уравнений в Unicode и LaTeX.
- Таблица Менделеева: 118 элементов, фильтры, раскраски и карточки.
- Шесть справочников с инструментами: растворимость, активность, электроотрицательность, Ka/Kb, электродные потенциалы и термодинамика.
- История 20 уравнений с фильтрами и избранным, RU/EN-словарь, светлая и тёмная темы.
- PWA: manifest, service worker, локальные SVG-иконки.

## Сообщество и модерация

Регистрация требует только логин, пароль и подтверждение пароля. Доступны три роли:

| Роль | Возможности |
|---|---|
| `basic` | Создавать и редактировать свои ожидающие заявки, снимать их, голосовать за чужие предложения один раз |
| `admin` | Возможности basic, редактирование ожидающих заявок, запрос источника, отклонение и публикация |
| `GOD` | Все возможности admin и назначение ролей `basic`/`admin`; создаётся один раз, его роль нельзя изменить через API |

Вкладка «Сообщество» содержит ленту с сортировкой по рейтингу или дате, персональные заявки, даты регистрации и последнего входа. Обновления доставляются через SSE; при разрыве соединения используется опрос каждые 30 секунд. Голоса помогают найти заявку, но **не публикуют её автоматически**.

«Предложить верное решение» доступно при отсутствии правила, а «Нашли неточность?» — рядом с результатом расчёта. В заявку переносятся реагенты и условия. До отправки проверяются атомный и зарядовый баланс; указываются источник, типы ошибок, пояснение, растворимость и ионный состав новых веществ. «Личное мнение» можно обсудить в ленте, но нельзя опубликовать без независимого источника. Водный обмен в неводной среде не принимается как новое правило; отдельный неводный процесс требует явного подтверждения и источника.

Утверждённое правило сохраняется в SQLite и экспортируется в версионированный `data/reaction-rules-community.json`. Перед заменой пакета запускается проверка всей базы. Исправление занимает место предыдущего активного правила, старые заявки остаются в истории. Открытый пакет используется калькулятором после обновления через API и остаётся доступен офлайн.

Пароли сохраняются только как salted scrypt-хэши, не в открытом виде. Сессия длится 12 часов; cookie имеет `HttpOnly` и `SameSite=Lax`, а при `NODE_ENV=production` — также `Secure`. Токен сессии хранится в базе хэшированным. Изменяющие запросы требуют отдельный CSRF-токен, а API не кешируется service worker. Ограничены размер запроса и частота попыток входа. Прав доступа проверяются на сервере, а не только скрытием кнопок.

Основная база — `var/community.db`; путь можно изменить через `COMMUNITY_DB`. Каталог `var` исключён из Git и не отдаётся статическим сервером. Для переноса сообщества нужны и SQLite-база, и экспортированный JSON-пакет.

## Практические сценарии

Встроенная глава «Документация → Практические шаги» содержит инструкции для каждого инструмента на русском и английском языках.

- Проверка: введите полное уравнение, выберите фазу и нажмите «Проверить». Индикатор LIVE не является итоговым вердиктом.
- Авто: для P + HNO₃ выберите кислую среду, концентрированную кислоту и нагревание. Для CrCl₃ + H₂O₂ + KOH — щелочную среду и нагревание.
- Стехиометрия: задайте известную массу, количество, объём газа или раствора, затем выберите условия газа и целевой продукт для практического выхода.
- Справочники: проверяйте пару ионов, вытеснение металла, тип связи, pH, буфер, гальванический элемент, Нернст и Гесса на примерах из главы.
- Таблица: откройте её клавишей T, выберите «Справка» или «Вставка». В полноэкранном режиме используйте явную кнопку выхода.
- Экспорт и история: копируйте Unicode/LaTeX, делитесь ссылкой с условиями, отмечайте избранное и фильтруйте последние 20 записей.
- Состояние: фаза «Проверки» передаётся в ионные и термодинамические расчёты и сохраняется в истории. Панель ОВР очищается перед новым результатом и при сбросе.

## Научные границы

Режим «Авто» — это конечный набор правил, а не универсальный химический предсказатель. Он показывает уверенность, допущения и отказывается от ответа при отсутствии правила. Сложные реакции могут зависеть от соотношения реагентов, кинетики, пассивации, комплексообразования и побочных процессов. В режиме недостатка щёлочи H₂SO₄, H₃PO₄ и H₂S нейтрализуются только по первой ступени. Средние степени окисления углерода не заменяют структурный анализ отдельных атомов в произвольной органической молекуле. Для CH₃CHO, CH₃COOH и CH₃CH₂OH есть явные записи функциональных центров: метильная группа сокращается, а переход альдегидного углерода рассчитывается как +1 → +3 (по 2e⁻ на атом).

Термодинамический расчёт не выполняется, если отсутствует хотя бы одно вещество с подходящим стандартным состоянием. Для ΔG(T) предполагается независимость ΔH° и ΔS° от температуры; фазовые переходы и Cp в этом приближении не учитываются. pH использует идеальные концентрации вместо активностей. Правило Δχ для типа связи ориентировочно. Положительная ЭДС не гарантирует скорость реакции.

«—» означает отсутствие значения в выбранном источнике. Неизвестные значения не вычисляются и не выдумываются.

## Структура

- `js/parser.js`, `balancer.js`, `redox.js`, `internal-redox.js`, `checker.js`, `predictor.js` — химическое ядро, включая внутримолекулярные ОВР.
- `js/reaction-conditions.js` — единая проверка фазы и блокировка водных ионных механизмов в неводной среде.
- `js/redox-predictor.js` — ионные ОВР по электродным парам и стандартной ЭДС.
- `js/redox-view.js` — гарантированная очистка и обновление панели ОВР перед каждым результатом.
- `js/ionic.js`, `electrolytes.js`, `dissociation.js`, `stoichiometry.js`, `thermo.js` — ионные формы, распознавание электролитов и расчёты.
- `js/export.js` — экспорт разобранных уравнений в LaTeX.
- `js/periodic-table.js`, `periodic-card.js` — таблица и карточки.
- `js/reference-tables.js`, `reference-ui.js` — справочники и инструменты.
- `js/community-ui.js`, `js/auto-ui.js`, `js/ui.js` — аккаунт, заявки, голосование, модерация и связь с калькулятором.
- `server.mjs`, `server/*.mjs` — HTTP API, SQLite, scrypt, сессии и CSRF, валидация и версионированный экспорт правил.
- `data/reaction-rules-community.json` — опубликованные модераторами правила и новые вещества.
- `data/*.json` — встроенные данные; внешние запросы во время работы не выполняются.
- `scripts/*.mjs` — воспроизводимое преобразование открытых исходных данных.

## Источники и условия

| Данные | Источник и год | Условия |
|---|---|---|
| Атомные массы | CIAAW, Standard Atomic Weights 2021 | conventional abridged values; для радиоактивных элементов используется условное массовое число |
| Свойства элементов | Bowserinator Periodic-Table-JSON; ссылки на Wikipedia сохранены для каждого элемента | K, pm, kJ/mol; плотность приведена к g/cm³; null сохраняется как отсутствие данных |
| Ионные радиусы | R. D. Shannon, Acta Cryst. A32 (1976), 751; таблицы WebElements | 31 радиус Li–Br, кроме Ne и Ar; указаны ион, CN и спиновое состояние; это не радиусы нейтральных атомов |
| История магния | RSC, Chemistry in its element: magnesium | Joseph Black, 1755; ссылка добавлена в карточку Mg |
| Русские дополнения | Самостоятельные краткие тексты по общеизвестным свойствам; источник элемента указан в карточке | Для непроверенных полей используется null |
| Растворимость | Глинка Н. Л., «Общая химия»; Ksp — CRC Handbook | Ksp при 25 °C; качественные школьные категории |
| Ряд активности | Глинка Н. Л., «Общая химия» | Практический ряд с отдельными оговорками |
| Электроотрицательность | Periodic-Table-JSON / данные по шкале Полинга | Безразмерная шкала Полинга; другие шкалы не показаны без надёжных данных |
| Ka/Kb | CRC Handbook of Chemistry and Physics, 97th ed.; NIST Chemistry WebBook | 25 °C, водный раствор; округлённые pKa/pKb |
| Электродные потенциалы | CRC Handbook of Chemistry and Physics, 97th ed.; соглашение IUPAC | 25 °C, 1 М, 1 бар, относительно СВЭ |
| Термодинамика, основной набор | CRC Handbook of Chemistry and Physics, 2014; извлечение CalebBell/chemicals | 298,15 K, 1 бар; 393 записи с полными ΔfH°, ΔfG°, S°; Cp при наличии |
| Водные ионы и дополнения | OpenStax Chemistry 2e, Appendix G; Chemistry LibreTexts T1 / CRC 84th ed. (2004) | 298,15 K, 1 бар; фаза aq; стандартная шкала H+(aq) = 0 |
| K2FeO4(s) | Sharma et al., J. Chem. Eng. Data 55(12), 2010, DOI 10.1021/je100417d | ΔfH° = −1026±4 кДж/моль, ΔfG° = −896±8 кДж/моль, S° = 130±17 Дж/(моль·K); только твёрдая фаза |

Всего 486 термодинамических записей, 264 вещества с русскими названиями, 332 правила реакций, 38 электродных пар и 124 явные записи ионного состава. Дополнительные типовые соли щелочных металлов и аммония распознаются по проверенному перечню анионов; комплексные и специфические малорастворимые соли автоматически растворимыми не считаются. Для простых веществ в стандартном состоянии ΔfH° = 0 и ΔfG° = 0. Если CRC оставляет ΔfG° пустым при ΔfH° = 0, генератор явно добавляет ноль по определению стандартного состояния. Графит и алмаз являются разными строками; в расчётах C(s) выбирается графит. Водный режим ищет записи aq для растворимых веществ и не подставляет твёрдую фазу. Данные K2FeO4(s) не подставляются как данные водного раствора. Для этанола, диметилового эфира, ацетальдегида и других изомеров выбор выполняется по структурной формуле и CAS; одинаковая суммарная формула сама по себе не различает изомеры.

## Повторная генерация данных

```bash
node scripts/build-elements.mjs /path/to/PeriodicTableJSON.json
node scripts/enrich-elements.mjs
node scripts/build-thermo.mjs /path/to/CRC.tsv /path/to/pubchem-small.tsv /path/to/inorganic.tsv
node scripts/build-electronegativity.mjs
```

Генераторы нужны только разработчику и не выполняются приложением. После базового `build-elements.mjs` запускается идемпотентный `enrich-elements.mjs`: он заполняет только пустые ионные радиусы и добавляет источник истории Mg, не перезаписывая подтверждённые данные. Внешние сайты используются разработчиком для проверки источников, а не приложением во время расчёта.

## Доступность

Семантические области, видимый фокус, клавиатурная навигация, 44 px цели касания, статусы с текстом и значками, `prefers-reduced-motion`, внутренняя прокрутка больших таблиц. Таблица Менделеева открывается кнопкой или клавишей T.
